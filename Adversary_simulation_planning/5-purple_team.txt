## 4. Recommendations Per Undetected Technique

**T1547.001 - Registry Run Keys / Startup Folder**

Implement a SIEM detection rule monitoring Windows Registry Run and RunOnce key modifications using Sysmon Event ID 13 and Windows Security Event ID 4657, where enabled. Generate alerts for suspicious autorun entries and validate detection using controlled persistence simulations.

**T1218.005 - System Binary Proxy Execution: Mshta**

Configure EDR/SIEM monitoring for unusual `mshta.exe` execution using Sysmon Event ID 1 or Windows Security Event ID 4688. Alert when `mshta.exe` executes remote content or launches suspicious child processes such as PowerShell, and verify the rule through authorized lab testing.

## 5. Executive Summary

The Purple Team exercise evaluated five attack techniques associated with the FIN7 threat scenario, and the Blue Team successfully detected three, achieving a 60% detection rate. The average detection time was 32 minutes, exceeding the provisional 15-minute target and leaving important security gaps in persistence and defense-evasion monitoring. We recommend improving detection rules for the two missed techniques, reducing response delays, and repeating the exercise to confirm measurable improvements.
